Comment jouer

Devine le mot mathématique du jour en 6 essais. Le nombre de cases indique le nombre de lettres.

Après chaque essai, les couleurs t'aident :

S
I
N

Vert : bonne lettre, bonne place.

R
A
D

Jaune : la lettre est dans le mot, mais ailleurs.

P
I
X

Gris : la lettre n'est pas dans le mot.

Les accents sont ignorés (PÉRIODE s'écrit PERIODE). Un nouveau mot chaque jour de classe !
